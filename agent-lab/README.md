# Agent MusicXML Lab

Say:

```
action prompt agent-lab/tasks/T01-transpose-up-major-second.md
```

That is the whole interface. I write the score into `out/`, then MuseScore opens, the PDF opens, and the music plays. Do not look for files.

Re-present whatever is currently in `out/`:

```bash
./agent-lab/scripts/present-score.sh
```
